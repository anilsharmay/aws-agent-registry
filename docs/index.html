CONFERENCE SESSION

Scaling agents starts with governed discovery

As enterprises move from experiments to implementation, unmanaged agents, tools, skills, and MCP servers create a new operating problem: teams cannot reliably discover, govern, or reuse what already exists.

This first-look session examines how AWS Agent Registry organizes resource metadata, separates publisher and curator responsibilities, controls discoverability through approval, and brings governed search into the engineering workflow.

SESSION SCOPE

What the session covers

  1. Agentic sprawlWhy resource visibility, control, and reuse become enterprise architecture concerns.
  2. Registry modelRegistries, records, descriptors, versions, publishers, curators, and consumers.
  3. Governance lifecycleDraft, submission, approval, rejection, deprecation, and approved-only discovery.
  4. Hybrid discoveryKeyword and semantic-style search inside an explicit governance boundary.
  5. MCP integrationUsing the Registry MCP endpoint from compatible developer environments.
